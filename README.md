# events-daily

Daily email digest of today's events from tracked org/venue pages, with one-click "Add to Calendar" links. Runs as a Claude Code Routine — see `dev/PRD.md` for the full design.

## Setup

After cloning the repo:

1. In Claude Code, invoke the `setup-events-daily` skill and follow it through (connectors, Airtable tables, sources, routine creation).
2. Manually trigger the routine once to confirm it runs end-to-end.
