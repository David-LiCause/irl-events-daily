# Sources

Event sources live in the `Sources` table in Airtable (not in this repo; see `docs/SETUP.md` for how the base is created), columns: `Name`, `URL` — one row per org/URL pair. An org with multiple relevant pages gets multiple rows with the same `Name`.

For the first end-to-end test, only one real event-page URL is needed. Add/edit/remove rows directly in Airtable as the list changes over time.
